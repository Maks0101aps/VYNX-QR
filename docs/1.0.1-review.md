# 1.0.1 preparation (unreleased)

Fixed duplicate Customize controls, independent colour swatches, preservation
of the last valid colour while editing, and default/reset colours. PNG, SVG
and clipboard exports now use the selected export size.

The original-text action stays visible and can return to detected content;
original text preserves surrounding whitespace. Settings update the palette,
stylesheet and Windows title bar immediately. DWM calls use the SDK attributes
and correctly sized values. Logo drops are handled by the accepting widget.

Logo dimensions are checked before pixel decoding, with decoder dimension and
allocation limits. Wi-Fi SSIDs use the 32-byte limit; WPA accepts 8–63 printable
ASCII characters or a 64-digit hexadecimal key.

Saving uses QSaveFile and checks both the write and commit results. UI
regressions cover Customize, PNG/SVG/clipboard exports, theme switching,
original text and logo drops. Debug was already guarded correctly and is
verified separately without Qt/window targets.

The return action names the detected kind (URL, Email or Phone), and padded plain
text offers no toggle because its payload already preserves the exact input.

Installer and portable packages include full LGPL/GPL texts, the unmodified
Qt Base 6.8.3 source archive verified by SHA256, and DLL replacement
instructions. The application licence explicitly preserves LGPL library
modification and related reverse-engineering rights. The source archive is
embedded in both packages, so the three public release artifact names remain
installer, portable ZIP and checksum manifest.

Rust licences are generated at packaging time with pinned cargo-about, covering
the Windows production graph from bridge/Cargo.lock, including exact versions,
full licence texts and upstream copyright/NOTICE files. The generated manifest
records source-file hashes; installer smoke verifies them after installation.

Before publication: run CI for the final commit on main, dispatch Release
without a tag, and require installer smoke success on windows-2022 and
windows-2025 for these new packages. Earlier 1.0.0 smoke results do not validate
these changes. Dedicated clean Windows 10 validation remains pending.
