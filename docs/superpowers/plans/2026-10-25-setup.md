# Branded setup implementation plan

**Goal:** Deliver a working Windows and Linux graphical installer following the supplied dark blue VYNX QR reference.

**Architecture:** Share a Qt Widgets wizard inside the existing executable. Windows uses a silent NSIS installation backend and a silent self-extracting bootstrap that launches the wizard. Linux Setup AppImage opens the same wizard, installs the AppImage per user and registers a desktop entry; package-manager formats retain their normal behavior.

**Design:** 760 × 510 logical pixels, native resizable window, navy #0b1321 canvas, #101e34 sidebar, #1761f5 action, #edf3ff text, #95a4bc secondary text. Four visible steps, existing product icon, Russian copy matching the reference. Folder validation, honest busy progress, visible errors and retry, launch checkbox on completion. Native title bar preserves dragging, keyboard and window-manager behavior.

**Constraints:** No elevation, network download, new UI runtime or version bump. Keep silent Windows installation, preferences and existing distribution formats. Never delete arbitrary folder contents. Work in the user's current checkout as requested.

1. Add backend and wizard behavior tests: folder validation, missing payload failure, navigation and recovery; Linux install/uninstall in temporary directories including special-character paths and existing foreign files.
2. Implement the shared setup window and asynchronous platform backend, wire command-line setup and uninstall modes.
3. Wrap NSIS backend with the Qt bootstrap, add Linux Setup AppImage artifact, checksums and release collection; add Linux lifecycle smoke coverage.
4. Build on the available host, run Qt tests, inspect actual rendered screens, exercise the packaged Windows install and uninstall in a dedicated folder while protecting existing registrations. Record platform validation limitations.

Review focus: Unicode/spaced paths; existing unrelated files; backend failure; closing while installation runs; launching after bootstrap cleanup; Linux desktop escaping and ownership.
